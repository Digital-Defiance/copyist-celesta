# Copyist celesta samples

A compact mono subset of [Neil Bickford's A Sampled Celesta](https://gitlab.com/Nbickford/a-sampled-celesta) (CC0), for [Copyist](https://github.com/Digital-Defiance/copyist) exact previews.

Source: Tuned Denoised Mix soundfont, every whole tone from C4–C8, L+R summed to mono, ~2.2 s per note. About 5 MB.
